## 2. Ⅱ 평가의 목적 — 5개가 표준, 고정은 아니다

| 항목 수 | 과목 수 |

양식에 5개(가~마)가 들어 있고, 렌더는 **가·나·다만** 갈아끼우고 라·마는 양식

```
마. 교육 내용, 학습 요소, 학습활동의 적절성을 평가하여 교수·학습 방법을 개선하기 위한 평가이다.
```

**→ 지금 구조가 맞다. 바꿀 것 없음.**

## 3. Ⅲ-1 평가의 기본 방향 — 10개가 표준

| 항목 수 | 과목 수 |
|---|---|
| **10개** | **49** |
| 8개 | 2 |
| 13개 | 2 |
| 6·9·11개 | 각 1 |

구조는 이렇게 갈린다.

```
가.  학습자의 ○○ 능력의 신장과 발달 정도를 판단하기 위해 평가한다.       ← 과목별
나.  성취도는 기준 성취율에 따른 {추정|고정}분할점수로 설정하여 산출한다.  ← 계산값
다.  ○○의 실제성이 드러나도록 평가 과제·상황을 실제 삶의 맥락에서 …      ← 과목별
라.  학습자의 수준·관심·흥미·진로 등 개인차를 고려하되, ○○ 과정과 결과 … ← 과목별
마~차 (6문장)                                                          ← 학교 공통
```

마~차 여섯 문장은 표기 흔들림(`창의·융합적`/`창의융합적`, `성취기준`/`성취 기준`)만
빼면 **전 과목 동일**했다.

### 번호가 어긋난 실물

우리는 번호를 출력 시점에 붙이므로 이런 어긋남이 생기지 않는다.

## 4. 🐛 분할점수가 반영되지 않던 버그 — 고침

양식 Ⅲ-1 `나`에 **`추정분할점수`가 검정 글씨로 박혀** 있는데 렌더가 이 줄을
건드리지 않았다. 그래서 **고정분할을 고른 계획서도 문서에는 "추정"이라고 나갔다.**

```
추정 → 나. 성취도는 기준 성취율에 따른 추정분할점수로 설정하여 산출한다.
고정 → 나. 성취도는 기준 성취율에 따른 고정분할점수로 설정하여 산출한다.
```

AI 초안이 아니라 계산값이므로 검정 글씨 그대로 둔다.
분할점수 선택은 기본설정에 넣었다.

### 남은 판단 — Ⅲ-2 `나`

`평가의 실시 전, 산출된 추정분할점수를 … 공지함으로써 …` 도 같은 문제다.
**그런데 실물 2학년 파일은 고정분할인데 이 줄이 여전히 "추정분할점수 공지"다.**
원본에서 안 고친 것으로 보인다. 학교 관행일 수 있어 임의로 바꾸지 않았다.
**사용자 판단 필요.**

## 5. Ⅳ 평가의 종류와 방법 — 가장 큰 발견

실물 57개의 표 모양이 11가지였다.

| 열 구성 | 과목 수 | 보기 |
|---|---|---|
| 6열 · 정기 0 · 수행 3 | **24** | 과학탐구실험1, 미술, 체육1, 진로와 직업 |
| 7열 · 정기 2 · 수행 2 | 8 | 공통국어1, 한국사1, 현대사회와 윤리, 물리학 |
| 9열 · 정기 4 · 수행 2 | 8 | 통합과학1, 영어Ⅰ, 세계사, 생활과 윤리 |
| 11열 · 정기 6 · 수행 2 | 5 | 공통수학1, 대수, 생명과학, 미적분, 확률과 통계 |
| 7열 · 정기 0 · 수행 4 | 3 | 음악, 융합과학 |
| 8열 · 정기 3 · 수행 2 | 3 | 문학, 일본어, 화법과 작문 |
| 나머지 6가지 | 6 | 기술가정, 공통영어1, 경제, 생활과 과학 … |

여기서 규칙이 나온다.

> **정기시험 한 회차는 그 시험지를 몇 가지 문항 유형으로 나눠 채점하느냐만큼
> 열을 차지한다.**

실물 세 과목의 `평가 방법` 줄을 나란히 놓으면 바로 보인다.

```
공통국어1 (7열) ─ 회차당 1유형 → 정기시험 2열
  정기시험(60%)······2열      수행평가(40%)······2열
  ├ 1회: 선택형              ├ 도서 비평: 논술형, 구술형
  └ 2회: 선택형              └ 시사 탐구: 보고서

통합과학1 (9열) ─ 회차당 2유형 → 정기시험 4열
  정기시험(60%)······4열      수행평가(40%)······2열
  ├ 1회: 선택형 · 단답형       ├ 원소의 주기성: 서술형
  └ 2회: 선택형 · 단답형       └ 유전자의 중심원리: 서술형

공통수학1 (11열) ─ 회차당 3유형 → 정기시험 6열
  정기시험(60%)······6열      수행평가(40%)······2열
  ├ 1회: 선택형 · 단답형 · 서술형   ├ 방정식과 부등식: 논술형
  └ 2회: 선택형 · 단답형 · 서술형   └ 도서 기반 주제: 보고서
```

`영역 만점` 줄을 보면 확실해진다. 공통수학1은 `70점 10점 20점 / 70점 10점 20점`
으로 **회차마다 세 칸**이고, 공통국어1은 `100점 / 100점`으로 **한 칸씩**이다.

그리고 행마다 병합이 다르다.

- `평가 방법`·`영역 만점` → 문항 유형별로 **쪼갬**
- `반영 비율`·`서술형․논술형`·`성취 기준`·`평가 시기` → 회차 하나가 그 유형들을 **통째로 덮음**

### 고친 것

기존 코드는 **첫 회차만 쪼개진다**고 보고 있었다(`parts.length + (회차수-1)`).
수학처럼 두 회차 모두 3유형이면 열이 모자라 값이 밀린다.

- `examCols = Σ(회차별 문항 유형 수)` 로 교정
- `doc.setItemSpans()` 신설 — 행마다 병합 폭을 따로 지정
- `fitItemCols` 버그 — 열을 늘릴 때 **병합된 칸을 그대로 복제**해 열이 여러 칸씩
  불어났다. 복제본은 폭 1로 되돌린다

검증한 모양 (전부 렌더 경고 0):

| 조건 | 결과 | 실물 대응 |
|---|---|---|
| 수행 100% + 3개 | 6열 · 수행평가(100%)×3 | 24건 무리와 일치 |
| 정기 2회(2유형) + 수행 2 | 9열 · 정기×4 · 수행×2 | 8건 무리와 일치 |
| 정기 2회(3유형) + 수행 2 | 11열 · 정기×6 · 수행×2 | 수학 5건과 일치 |

**GPT 분석에는 이 항목이 없다.** 문단 텍스트만 봐서는 열 구조가 보이지 않는다.

## 6. Ⅺ 나. 학기단위 성취수준 — 강도 변형

A~E가 서로 다른 다섯 문장이 아니라 **한 문장의 수행 강도만 바꾼 것**이다.

```
A 종합적으로 이해하고 다양한 사례를 들어 …
B 고려하여 문학 작품을 감상하고 …
C 고려하여 문학 작품을 이해할 수 있다
D 부분적으로 고려하여 …
E 제한적으로 이해한다
```

프롬프트가 "상위 수준일수록 수행의 폭과 자립도가 커지게"라고만 말하고 있어서
다섯 문장을 따로 지어내고 있었다. **뼈대는 같게 두고 부사와 서술어만 바꾸라고
명시**하도록 고쳤다. (GPT 분석과 동일 결론)

## 7. GPT 분석과 갈리는 두 곳

### ① Ⅱ — "가·나만 AI" (GPT) vs "가·나·다" (현행)

**현행 유지가 맞다.** 양식의 `다`는 `일상생활과 사회에서 발생하는 다양한 문제에
대한 …` 로 **통합사회 전용 문장**이다. `다`를 AI에서 빼면 국어 계획서에 통합사회
문장이 그대로 남는다.

실물에서도 `다`는 과목별인 경우가 있었다.

- 1학년 공통국어1: `다. 공동체의 언어문화를 탐구하여 …` ← 과목별
- 2·3학년: `다. 표현 능력과 이해 능력 …` ← 공통에 가까움

**섞여 있으므로 AI에 맡기는 쪽이 안전하다.** 반대로 하면 남의 과목 문장이 샌다.

### ② Ⅲ-1 — "첫 문장만 AI" (GPT) vs "가·다·라" (현행)

**현행 유지가 맞다.** `다`와 `라`에도 과목명이 들어간다.

```
다. 국어 사용의 실제성이 …        / 다양한 문학 경험과 활동의 실제성이 …
라. … 학습자의 국어 활동의 과정과 …  / … 학습자의 문학 감상 과정과 …
```

`가` 하나만 AI로 두면 `다`·`라`에 양식의 통합사회 문장이 남는다.
