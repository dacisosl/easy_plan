## 0. 왜 하는가

지금 코드의 문장은 전부 **내가 양식 메모를 보고 추측해서 쓴 것**이다. 실물과 대조해
보니 항목 수부터 틀렸다. 실물에서 뽑은 사실로 갈아끼운다.

**대상은 다섯 곳뿐이다.**

| 구역 | 무엇을 | 지금 상태 |
|---|---|---|
| Ⅰ 교수학습 운영계획 | 내용과 구조 | **서술 칸 유무 불명** |
| Ⅱ 평가의 목적 | 가~마 | 코드가 3개만 만듦 → **5개** |
| Ⅲ-1 평가의 기본 방향 | 가~라(실물은 가~자) | 코드가 3개만 만듦 → **9개** |
| Ⅳ 평가의 종류와 방법 | 표 모양 | 이미 맞춤 (`e1cbfe5`) |
| Ⅺ 나. 학기단위 성취수준 | A~E + 최소 | 채우고 있으나 문장 패턴 미반영 |

**Ⅵ 수행평가 세부기준(루브릭)은 건드리지 않는다.** 교사가 한글에서 직접 고치는
자리라 본보기를 모을 이유가 없다. (사용자 지시)

## 1. 막힌 것 — 파일 두 개가 `.hwp`

`samples/`의 1학년·3학년 파일은 확장자만 `.hwpx`이고 실제로는 구버전 한글
바이너리다. 앞 4바이트가 `d0cf11e0`(OLE2 복합문서), 열리는 파일은 `504b0304`(zip).

### 해결: 직접 읽는다

`node_modules/cfb`(SheetJS가 딸려 온 것)로 OLE2를 열 수 있음을 확인했다.
HWP 5.0 구조는 이렇다.

```
OLE2 복합문서
 ├ FileHeader          (플래그에 '압축 여부' 비트)
 ├ DocInfo             (zlib raw deflate)
 └ BodyText/Section0…  (zlib raw deflate)
     └ HWPTAG_PARA_TEXT 레코드 안에 UTF-16LE 본문
```

**정밀 파싱은 하지 않는다.** 표 구조까지 복원하려면 레코드 트리를 전부 해석해야
하는데, 목적이 '문장 수집'이므로 과하다. 압축을 풀고 UTF-16LE 글자만 긁어
**문단 텍스트**를 얻는 선에서 끝낸다.

- 얻는 것: Ⅱ·Ⅲ-1 항목 문장, Ⅺ 학기단위 성취수준 문장, Ⅰ에 서술 문단이 있는지
- 못 얻는 것: 표의 열 배치(`colSpan`·`colAddr`)

표 구조가 필요하면 그때 HWPX 재저장을 요청한다. 지금 필요한 Ⅳ 표 구조는
이미 `.hwpx`로 받은 예시로 해결됐다.

**산출물**: `scripts/read-hwp.ts` — `.hwp`에서 문단 텍스트만 뽑는다.
실패하면 조용히 건너뛰고 경고만 남긴다. 여기서 막히면 계획대로 재저장을 요청한다.

## 2. 확인된 사실 (2학년 문학, 읽힌 파일)

### Ⅲ-1의 실제 모습

```
가. 학습자의 문학 감상 능력의 신장과 발달 정도를 판단하기 위해 평가한다.   ← 과목마다 다름
나. 성취도는 기준 성취율에 따른 고정분할점수로 설정하여 산출한다.          ← 분할점수
나. 다양한 문학 경험과 활동의 실제성이 드러나도록 …                        ← 이하 학교 공통
다. 학습자의 수준, 관심, 흥미, 진로 등 개인차를 고려하되 …
라. 평가는 선다형, 서술형 및 논술형, 관찰, 보고서 검토, 실기 검사 …
마. 평가는 창의·융합적 문제 해결력 및 인성과 감성 함양에 …
바. 평가는 개별 평가와 더불어 협동심을 함양하기 위한 모둠 평가를 실시한다.
사. 타당도와 신뢰도가 높은 평가가 될 수 있도록 …
아. 평가는 설정된 성취 기준에 근거하여 실시하고 …
자. 평가는 평가 계획 수립, 평가 문항과 도구 개발 … 절차를 거쳐 실시한다.
```

읽어낸 것 세 가지.

1. **`나`가 두 번 나온다.** 분할점수 문장을 나중에 끼워 넣고 뒷 번호를 안 고친
   원본의 실수다. 우리는 번호를 출력 시점에 붙이므로 저절로 바로잡힌다.
2. **`가`만 과목마다 다르다.** 나머지는 학교 공통 문구다.
3. **`나`가 사용자가 말한 그 자리다.** 분할점수 방식에 따라 갈린다.

→ **AI가 쓸 것은 `가` 하나뿐이다.** 나머지는 문장 은행에 고정으로 박는다.
지금처럼 9개를 AI에 맡기면 매번 다른 말이 나오고 학교 지침과 어긋난다.

### Ⅱ 평가의 목적 — 다섯 개, 전부 과목마다 다름

```
가. 문학 작품의 수용과 생산 활동을 중심으로 … 능력을 평가한다.
나. 문학의 본질과 양상에 대한 이해력을 비롯하여 … 평가하도록 한다.
다. 표현 능력과 이해 능력, 인지적·행동적·정의적 요소가 균형을 이루도록 평가를 구성한다.
라. 학생들이 성취해야 할 목표(성취 기준)에 도달한 정도를 평가하며 …
마. 교육 내용, 학습 요소, 학습활동의 적절성을 평가하여 교수·학습 방법을 개선하기 위한 평가이다.
```

`다`·`라`·`마`는 과목명만 바뀌는 정형문에 가깝고, `가`·`나`가 과목 색이 짙다.

### Ⅺ 학기단위 성취수준 — 같은 문장의 강도만 바꾼다

```
A 종합적으로 이해하고 다양한 사례를 들어 …
B 고려하여 문학 작품을 감상하고 …
C 고려하여 문학 작품을 이해할 수 있다
D 부분적으로 고려하여 …
E 제한적으로 이해한다
```

A~E가 **독립된 다섯 문장이 아니라 한 문장의 수행 강도 변형**이다. 지금 프롬프트는
"상위 수준일수록 수행의 폭과 자립도가 커지게"라고만 말한다. 이 패턴을 명시한다.

### Ⅰ 교수학습 운영계획 — 서술 칸이 없다

양식에도 실물에도 이 구역은 **진도표 하나**로 끝나고 뒤에 `※ 단, 학사일정 등의
상황을 고려하여 변경하여 운영할 수 있음.` 만 붙는다. 그런데 코드는 여기에 AI
문장을 넣는다.

**미해결.** 나머지 파일을 읽어 서술 칸이 있는 과목이 하나라도 있는지 본다.

- 있으면 → 지금처럼 한 덩어리로 쓴다 (사용자 지시대로 교사 수와 무관하게 1칸)
- 없으면 → **Ⅰ에 문장을 쓰는 코드를 걷어낸다.** 양식에 없는 자리에 글을 넣는 셈이라
  문서가 원본과 달라진다

## 3. 할 일

### Phase 1 — `.hwp` 읽기 (`scripts/read-hwp.ts`)

`cfb`로 OLE2를 열고 `BodyText/Section*`을 raw inflate → UTF-16LE 문단 텍스트 추출.
`scan-samples.ts`·`extract-sections.ts`가 `.hwp`도 받도록 연결한다.

**검증**: 읽힌 2학년 파일을 `.hwp`로 저장해 대조… 는 불가하므로,
추출한 문장이 한국어로 읽히는지와 Ⅱ·Ⅲ 항목이 `가.`~로 잡히는지로 확인한다.

### Phase 2 — 세 학년 전수 조사

`extract-sections.ts` 결과로 답할 것.

- Ⅱ가 5개, Ⅲ-1이 9개가 **모든 과목에서 그런지** (한 파일로는 단정 못 함)
- Ⅲ-1 `가`, Ⅱ `가`·`나`가 과목마다 어떻게 다른지 → AI 프롬프트 본보기
- Ⅲ-1 `다`~`자`, Ⅲ-2 `가`~`차`가 전 과목 동일한지 → 고정 문장 확정
- **Ⅰ에 서술 칸이 있는 과목이 있는지**

산출: `out/sentences.md` (빈도순), `out/sections.json`

### Phase 3 — 문장 은행 교체 (`src/data/school.ts`)

- Ⅱ: 5개 자리 마련. `다`·`라`·`마`는 `{과목명}` 슬롯을 낀 고정 문장, `가`·`나`만 AI
- Ⅲ-1: `가`만 AI. `나`는 분할점수 조건부(이미 `3886b3c`에서 만듦). `다`~`자` 고정
- Ⅲ-2: 실물 `가`~`차` 10개와 지금 문장 은행 대조 후 보정

**주의**: 학교 고유 문구(세종시교육청 등)는 그대로 두되, 다른 학교에서 쓸 수 있게
`school.rules`에서 갈아끼울 수 있는 형태를 유지한다.

### Phase 4 — 프롬프트 · 대체 문구 (`src/lib/aiDraft.ts`)

- `sectionsPrompt`: II를 5개로, III1은 `가` 한 문장만 요구
- `semesterLevels`: A~E 강도 변형 패턴을 지시문에 명시 + 본보기 한 벌
- `fallbackSections`: 같은 구조로 맞춤 (키 없이도 형태가 맞아야 한다)

### Phase 5 — Ⅰ 처리 결정

Phase 2 결과에 따라 유지 또는 제거. 제거하면 `renderForm`의 Ⅰ 블록과
`sectionsPrompt`의 `I`, `fallbackSections.I`를 함께 걷어낸다.

## 4. 하지 않을 것

- **Ⅵ 수행평가 세부기준 분석** — 사용자 지시. 교사가 한글에서 고친다
- **`.hwp` 표 구조 복원** — 필요하면 HWPX 재저장을 요청하는 편이 싸다
- **실물 문서를 통째로 프롬프트에 넣기** — 토큰을 태우고 다른 학교 문장이 새어
  나온다. 문장 틀로 압축해서 넣는다
- **`samples/` 커밋** — 교사 실명·학교명이 들어 있고 저장소가 공개다
  (`.gitignore`에 걸어 뒀다)
