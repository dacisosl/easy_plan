# 참고자료 파일 두는 곳

여기에 파일을 넣으면 앱의 **참고자료 → 작년자료**에서 내려받을 수 있습니다.

- 파일을 넣고 `npm run build`(또는 `npm run deploy`)를 하면 목록이 자동으로 갱신됩니다.
- 목록에 보이는 이름은 확장자를 뗀 파일명입니다 — 파일명을 그대로 사람이 읽을 이름으로 지어 주세요.
  (예: `2025학년도 1학기 수학 평가계획서.hwp`)
- `index.json`은 빌드가 만드는 목록입니다. 직접 고치지 마세요.
- 이 폴더의 파일은 **누구나 내려받을 수 있는 공개 자료**가 됩니다.
